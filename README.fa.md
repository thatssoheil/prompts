# پرامپت‌های هوش مصنوعی - مجموعه پرامپت‌های کپی و جای‌گذاری

مجموعه‌ای از پرامپت‌های آماده برای هر چت هوش مصنوعی. **بدون نصب، بدون ترمینال، بدون دستور.** فقط متن را کپی کنید، داخل چت هوش مصنوعی بچسبانید و تمام. از هر مدل هوش مصنوعی که ترجیح می‌دهید استفاده کنید.

> **این برای چه کسی است؟** برای همه! اگر نمی‌خواهید چیزی نصب کنید یا از ترمینال استفاده کنید، این پرامپت‌ها همان نتایج حرفه‌ای را با یک کپی و جای‌گذاری ساده به شما می‌دهند.

**ریپازیتوری:** github.com/thatssoheil/prompts

---

## 📦 پرامپت‌های موجود در این مجموعه

فایل‌های داخل این ریپازیتوری را ببینید. هر فایل `.md` یک پرامپت آماده است. با گذشت زمان پرامپت‌های جدیدی اضافه می‌شوند، پس سر بزنید - این یک مجموعه در حال رشد است.

---

## 🚀 روش استفاده

1. هر فایل پرامپت `.md` را در این ریپازیتوری باز کنید.
2. همه‌چیز زیر خط `---` را کپی کنید.
3. داخل هر چت هوش مصنوعی بچسبانید (هر مدلی کار می‌کند).
4. دستورالعمل ساده انتهای آن را دنبال کنید (مثلاً به آن بگویید چه چیزی را تحلیل یا مربیگری کند).

تمام. بدون تنظیمات، بدون دستور.

---

## ⚡ تفاوت: پرامپت و اسکیل؟

هر دو همان نتایج حرفه‌ای را می‌دهند. تفاوت در **روش استفاده** است:

| | **پرامپت** (این ریپازیتوری) | **اسکیل** |
|---|---|---|
| **برای چه کسی** | کاربران عادی، مبتدیان | توسعه‌دهندگان |
| **نصب** | ندارد - کپی و جای‌گذاری | یک دستور با ترمینال |
| **کار با** | هر چت هوش مصنوعی (چت وب) | ایجنت‌های کدنویسی (Hermes، Codex، Cursor و موارد دیگر) |
| **تلاش** | چسباندن متن در چت | `npx skills add ...` |

نسخه توسعه‌دهنده را می‌خواهید؟ این پرامپت‌ها به‌صورت **اسکیل قابل نصب** هم در یک ریپازیتوری موجودند:
👉 [github.com/thatssoheil/skills](https://github.com/thatssoheil/skills)
